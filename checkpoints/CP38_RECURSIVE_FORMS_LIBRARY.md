# Albedo Quintessential Synth — CP38 / Recursive Forms

## Original, separately selectable preset library

24 new polyphonic timbres, **12 Resynthesis Forms + 12 Repetition Fields**.
The 64 existing factory patches retain their unchanged names and indexes
0–63. New program IDs are 64–87 and map one-to-one to the saved native C++
program bank; patch loader/host state can restore these values.

These are newly designed synthesizer instruments, **not sampled, extracted or
transcribed portions** of any Max Cooper recording. Inspiration is restricted
to musical sound-design concepts, tonal color, micro-modulation, envelopes and
pulse character. No artist endorsement or affiliation is implied.

## Reference interpretation

- **Resynthesis** (Max Cooper, *World Passing By*) — warm classic analog/Prophet-6
  chord colors with modulating harmonic and texture layers; reinterpret as
  independent playable keys, pads, lead and drones, without copying pitches,
  chord voicings, note timing or melodies.
  https://www.youtube.com/watch?v=Kpm1l0HfkV0
- **Repetition** (Max Cooper, *Yearning for the Infinite*) — short hypnotic stabs,
  rhythmic repetition, expanding fine-detail and structural density; reinterpret
  as polyphonic plucks, percussive tones, low pulses, kinetic keys and grain.
  https://maxcooper.net/yearning-for-the-infinite-album

## Architecture and parameter policy

Canonical metadata: `Albedo-JUCE-Native/Metadata/recursive_forms_bank.json`.
Native header: regenerated by `tools/generate_recursive_forms.py`, preserving
all 197 historical factory parameter IDs. Each new patch initializes an
existing trusted factory timbre before applying its **own** unique values for:

- Four engine methods and levels, partial/character parameters, selective
  unison detune.
- Seven Alchemical macros, A/B filter cutoffs and resonances.
- Real ADSR and per-voice modulation rates, amounts and slew.
- Engine coupling, four effects mixes, and cautious pre-FX/output levels.
- Some Repetition Fields enable the real 16-step amplitude gate, but no
  copyrighted MIDI motifs are embedded.
- Voice Mode ID3111 fixed at 0 to preserve 12-key polyphony for **all roles**;
  pitch guard and limiter remain enabled.

JUCE 8/WIN x64 runtime `AlbedoProcessor` reports 88 programs. Original state
indices 0–63 behave as before. Atlas gains a dedicated **Recursive Forms** tab
with Family/Role/Sort/Search; the original 8×8 factory matrix stays unchanged.
Program header, DAW program picker and native WebView2 preset bridge accept IDs
64–87. HTML preview without native host uses an original base patch as a
visual-only fallback; **authentic new timbres require the compiled plugin**.

## UI checkpoint

CP38 also uses a separate, embedded JavaScript rotary layer for continuous
ranges and translucent contextual signal graphs. It retains the original
HTML `input` elements and their host parameter callbacks, while menus,
toggles, the XY plane and step buttons keep their natural interactions.
The CP37 translucent ADSR editor stays separate and intact.
